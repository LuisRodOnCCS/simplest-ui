Instalación y modelo de uso

Importa CSS para la apariencia. Importa JavaScript únicamente para los elementos interactivos que necesites.

npm install @luisrodonccs/simplest-ui

import "@luisrodonccs/simplest-ui/tokens.css";
import "@luisrodonccs/simplest-ui/styles.css";
import "@luisrodonccs/simplest-ui/components.js";

Las cards, tablas, alertas y controles de formulario son componentes CSS: usa HTML semántico con clases ui-*. Solo los componentes documentados como Web Components se usan mediante etiquetas sui-*.

Convivencia con Bootstrap y Tailwind

Los prefijos ui-, sui- y --sui- evitan colisiones. Cuando otro sistema controla el reset, carga solo tokens y componentes.

Formularios nativos, estilos coherentes

Conserva los elementos HTML nativos, sus labels y validación. Simplest UI añade la presentación.

Consideraciones

Conecta siempre <label for> e id. Usa .ui-help o .ui-error como descripción asociada mediante aria-describedby.

Los controles no se convierten en sui-input o sui-select; siguen siendo controles nativos.

Tooltip y toast

Feedback breve y contextual, anunciado de forma accesible.

sui-tooltip

Define content o incluye contenido con slot. El elemento crea aria-describedby y role="tooltip".

import { SuiToast } from "@luisrodonccs/simplest-ui";

SuiToast.show({
  title: "Cambios guardados",
  message: "La operación se completó correctamente.",
  variant: "success",
  duration: 3200,
});

Patrones y accesibilidad

Un patrón CSS no es necesariamente un Web Component. Conserva la semántica y añade comportamiento de aplicación cuando corresponda.

Drawer: patrón CSS actual

.ui-drawer y .ui-drawer-backdrop son clases CSS. Todavía no existe <sui-drawer>; la aplicación debe proporcionar el comportamiento y el foco.
